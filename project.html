Smart parking prototype

Project overview

See how a parking sensor can help drivers find a space and operators spot faults.

● Simulated data

How detection works

The demo uses a simulated distance reading. A car arriving changes the reading from 180 cm to 35 cm. The bay becomes occupied because the reading is below the demo threshold of 60 cm.

What drivers see

The car park map shows which bays are available. Drivers can filter by bay type and select an available space.

What operators see

The control room shows occupancy and sensor health. Operators can simulate a sensor going offline and then restore it.

Try it in your presentation

Open Sensor Demo, choose a free bay, then click Car arrives. Switch to Find a Space to see the same bay marked occupied.
